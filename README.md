# The Sword, Shield, and Achilles' Heel: Characterizing the Linguistic Inductive Bias of LLMs for Spatial Reasoning in Navigation Planning

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)

This repository contains the official implementation for the paper **"The Sword, Shield, and Achilles' Heel: Characterizing the Linguistic Inductive Bias of Large Language Models for Spatial Reasoning in Navigation Planning"**.

## Overview

This research investigates how linguistic inductive biases affect Large Language Models' (LLMs) spatial reasoning capabilities in navigation planning tasks. We systematically characterize these biases across three critical dimensions:

1. **Structural Bias**: How information structure (flat, hierarchical, clustered) and compression levels (0%, 50%, 75%) affect model performance
2. **Information Completeness**: The impact of providing different combinations of spatial dimensions (geometry, topology, semantics)
3. **Conflict Sensitivity**: Model behavior when information sources contradict each other

### Key Findings

- LLMs exhibit strong structural preferences, with hierarchical formats showing significant performance advantages
- Information completeness shows diminishing returns — providing 2-3 dimensions is usually sufficient
- Models demonstrate inconsistent conflict resolution strategies, revealing an "Achilles' heel" in their spatial reasoning

## Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/navigation-planning-llm.git
cd navigation-planning-llm

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### Dataset Generation

Our dataset generation process is **fully automated, rule-based, and requires no human annotation or LLM-based annotation**. All 1,250 base query samples are generated with strict information equivalence guarantees.

```bash
# Generate complete dataset
python tools/generate_dataset.py --output_dir ./data_set --seed 42

# Validate dataset and check statistics
python tools/validate_dataset.py --base_dir ./data_set --validate --check_equivalence
```

### Running Experiments

#### Local Model Inference

For models <= 8B parameters (e.g., Qwen3-0.6B, Qwen3-1.7B, Qwen3-4B):

```bash
# Configure model path in run/run_local_qwen.sh
bash run/run_local_qwen.sh
```

#### API-based Inference

For models >= 8B parameters and API-only models:

1. Obtain API keys:
   - Qwen models: https://www.aliyun.com/benefit
   - GPT/Gemini models: https://api.laozhang.ai

2. Configure keys in `run/run_api.py`

3. Run inference:

```bash
bash run/run_api.sh
```

### Running Tests

```bash
# Run all tests
python tests/test_scene_serializer.py
python tests/test_generate_dataset.py
```

## Dataset Details

### Scene Types

| Dataset | Scenes | Queries/Scene | Total Queries | Description |
|---------|--------|---------------|---------------|-------------|
| R1 | 10 | 50 | 500 | Simple navigation (4-6 rooms) |
| R2 | 10 | 50 | 500 | Complex navigation (6-14 rooms, 5 complexity gradients) |
| Conflict | 5 | 50 | 250 | Conflict scenarios |

**Total**: 25 scenes, 1,250 queries

### Format Variants by Dataset

Each dataset uses different variant types matched to its experimental purpose:

**R1 — Structural Compression Variants (7 per scene)**:
- `flat`: Natural language narrative (0% compression)
- `hier`: Full hierarchical structure (0% compression)
- `hier_50`: 50% compressed hierarchical
- `hier_25`: 75% compressed hierarchical
- `clustered`: Zone-based clustering (0% compression)
- `clustered_50`: 50% compressed clustered
- `clustered_25`: 75% compressed clustered

**R2 — Dimension-Ablation Variants (11 per scene)**:
- `flat_full`: All dimensions (geometry + topology + semantics + history)
- `flat_topo_hist`: Topology + History only
- `flat_geom_rule_hist`: Geometry + Rules + History (inferred topology)
- `flat_sem_rule_hist`: Semantics + Rules + History (room-chain)
- Plus all 7 structural compression variants

**Conflict — Base + Conflict Variants (7 per scene)**:
- `flat_full`, `flat_topo_hist`, `flat_geom_rule_hist`, `flat_sem_rule_hist`: Base variants
- `conflict_topo`: Topology contradicts history
- `conflict_geom`: Geometry rule contradicts actual topology
- `conflict_sem`: Semantic chain contradicts history

### Information Equivalence Guarantee

All format variants encode the same underlying world state:
- All room IDs / indices preserved
- Complete topology encoded (explicitly or implicitly)
- Full history trace maintained
- Semantic information retained (compressed but recoverable)

## Reproducibility

### Deterministic Generation

The dataset generation is **completely deterministic**:

```bash
# Same seed always produces identical dataset
python tools/generate_dataset.py --seed 42
```

### Validation Script

Verify dataset integrity:

```bash
python tools/validate_dataset.py --base_dir ./data_set --validate --check_equivalence
```

Expected output: All 25 scenes valid, all 1,250 queries valid, information equivalence verified.

### Aggregating Results

After running inference, aggregate results for figure generation:

```bash
python tools/aggregate_results.py
```

This produces `final_stats/` CSV files used by the figure scripts.
