## Key Design Decisions

1. **World/Rendering separation**: Structured world data is independent of text serialization. The same world can be rendered into any format variant.

2. **Unified serialization engine**: All format variants (flat, hier, clustered x 3 retention levels) are generated by a single `SceneSerializer` class.

3. **Numeric index fallback**: Compressed formats may use numeric indices (1, 2, 3) instead of room IDs (R1, R2, R3). Equivalence checks accept both.

4. **Deterministic generation**: All randomness is seed-controlled. Same seed always produces identical output.

5. **Symbolic verification**: All query ground truths are computed by symbolic solvers (BFS, direct lookup, coordinate comparison), not by LLMs.

## Reproducibility

```bash
# Generate complete dataset (deterministic)
python tools/generate_dataset.py --output_dir ./data_set --seed 42

# Validate
python tools/validate_dataset.py --base_dir ./data_set --validate --check_equivalence

# Run tests
python tests/test_scene_serializer.py
python tests/test_generate_dataset.py

# Verify query ground truths
python tools/verify_queries.py data_set/R1/scene/scene_01.json
```
